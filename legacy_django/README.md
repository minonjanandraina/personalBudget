# Prototype Django (archivé)

Prototype réalisé avant le passage à l'application Android (sprints 0 à 3 : modèles, interface mobile, CRUD solde/types/budgets/paramètres).
Il sert uniquement de **référence fonctionnelle** (règles métier, tests). Il n'est plus maintenu.

Pour le relancer : `python -m venv .venv`, `pip install -r requirements.txt`, `python manage.py migrate`, `python manage.py runserver`.
